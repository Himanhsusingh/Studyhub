CBSE CLASS 10 — OFFLINE PREVIOUS-YEAR PAPERS PACK

Includes:
- Previous_Year_Papers_Offline_Library.html: searchable local catalogue.
- previous_year_papers/Science/: PDFs from the Science.zip archive you uploaded.
- previous_year_papers/Mathematics_Standard/: PDFs from the Mathematics_Standard.zip archive you uploaded.
- Study_Notes_Formulas_Quiz_and_Planners.pdf: starter revision pack (if included).

HOW TO USE:
1. Extract this ZIP completely using your phone's Files app or a ZIP extractor.
2. Open Previous_Year_Papers_Offline_Library.html in a browser to search the local list.
3. Tap "Open PDF" beside a paper. Or open any PDF directly with your PDF reader.
4. These files can be opened offline after extraction.

IMPORTANT:
- I included the uploaded archives' PDF files and preserved their filenames.
- The catalogue groups by the archive folder; check each paper's cover for exact year, subject and set.
- This package contains the papers supplied in the two ZIP files; it does not imply that every CBSE year or set is present.
- Official CBSE archive: https://www.cbse.gov.in/cbsenew/question-paper.html (internet required to access/download).
